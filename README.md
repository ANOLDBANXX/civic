# Civic - Next-Gen Social Media Web Application

**Civic** is an all-in-one social platform prototype combining short-form vertical videos (**TikTok** style), visual photo feeds (**Instagram** style), and real-time messaging (**WhatsApp** style).

## Logo Concept
The **Civic** app logo features a neon cyan & red gradient squircle enclosing a stylized continuous 'C'. The loop seamlessly fuses a video playback curve with a chat message indicator dot, giving it a modern icon aesthetic similar to Instagram, TikTok, and WhatsApp.

## How to Publish on GitHub Pages
1. Unzip the archive.
2. Create a new GitHub repository named `civic`.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
4. Navigate to **Settings > Pages**, select `main` branch, and hit **Save**.
